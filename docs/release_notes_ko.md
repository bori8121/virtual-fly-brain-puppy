## 가상 초파리 뇌 강아지 시뮬레이터 릴리스

### 이것이 무엇인가요?
- 이 프로그램은 **초파리 connectome 기반 신경 시뮬레이션**과 **가상 강아지 행동/시각화**를 결합한 Windows 앱입니다.
- 초파리 뇌 신경 활동을 기반으로 강아지의 상태와 행동 변화를 관찰할 수 있습니다.

### 설치 방법
1. 이 릴리스의 `VirtualFlyBrainPuppyInstaller_*.exe` 파일을 다운로드합니다.
2. 파일을 더블클릭하여 설치를 시작합니다.
3. 설치 마법사의 안내에 따라 다음을 눌러 설치를 완료합니다.
4. 설치 후 시작 메뉴 또는 바탕화면 아이콘에서 앱을 실행합니다.

### 사용 방법
- 앱 실행 후 시뮬레이터 창에서 **재생/일시정지** 버튼으로 동작을 제어합니다.
- **속도 슬라이더**로 시뮬레이션 진행 속도를 조절합니다.
- **연결망 복잡도 옵션**으로 코어/전체 수준의 신경망 밀도를 선택합니다.
- GUI의 신경 활동 히트맵과 행동 로그를 보며 상태 변화를 확인합니다.

### 시스템 요구사항
- 운영체제: **Windows 10 또는 Windows 11 (64-bit)**
- 메모리: **최소 8GB RAM 권장**
- 저장공간: **최소 2GB 여유 공간**
- 별도 Python 설치 불필요 (모든 의존성 포함)

### 포함 기능
- 3000+ 뉴런, 548,000+ 시냅스 규모 connectome 처리
- 신경 상태(전압/칼슘) 기반 시뮬레이션
- PyQt5 기반 그래픽 사용자 인터페이스
- 실시간 신경 활동 시각화 및 행동 관찰
